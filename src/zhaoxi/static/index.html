本机模型约 90 MB，首次使用会下载。聊天内容在本机转换成向量，不需要额外 API Key。模型准备期间会提示检索降级。后台仅使用一个 CPU 线程。

历史检索与「计划与记忆」的结构化自动记录分开。关闭检索保留已有聊天。更换向量模型或检索范围后，暂停当前机器人，重建索引，再恢复连接。首次使用会自动建立索引。

每月用量
所有机器人共用这份月额度。按实际返回用量结算，包含聊天、主动关心和搜索中的模型调用；不是服务商账户余额。
